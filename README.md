
# 🗄️ SQL Server DBA Labs

### Hands-on SQL Server Administration | Performance Tuning | Backup & Recovery | HA/DR

Welcome to my SQL Server Database Administration laboratory repository!

This repository documents my hands-on learning journey as I refresh and expand my SQL Server DBA skills, building on my previous professional experience in database administration and IT consulting.

The goal is to develop a structured technical portfolio covering SQL Server administration, troubleshooting, performance optimisation, security, backup and recovery, and high availability.

Each laboratory will include practical scripts, technical documentation, test results, and lessons learned.

---

## 🎯 Project Objectives

The main objectives of this repository are:

- Strengthen my SQL Server database administration knowledge.
- Practice essential daily DBA operations.
- Develop troubleshooting and performance tuning skills.
- Explore modern SQL Server features and best practices.
- Build practical experience with High Availability and Disaster Recovery.
- Document technical procedures and solutions.
- Prepare for advanced database administration and Microsoft DP-300 certification studies.

## 🧪 Laboratory Documentation

Each laboratory will follow a consistent documentation structure.

### 1. Objective

Describe the technical problem or administration task being studied.

### 2. Environment

Document the SQL Server version, operating system, tools, and prerequisites.

### 3. Implementation

Explain the procedures and include the T-SQL scripts used during the exercise.

### 4. Validation

Verify that the procedure worked as expected and record the results.

### 5. Troubleshooting

Document errors, unexpected behaviour, investigations, and solutions.

### 6. Lessons Learned

Summarise the knowledge acquired and identify possible improvements.
